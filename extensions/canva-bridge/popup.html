Import bridge

Open Design Studio

1

Download from Canva

Checking the current tab…

In Canva, choose Share → Download and confirm the download yourself. Use SVG for supported vector elements, PPTX for presentations, or PNG/JPG for a page image.

2

Prepare your export

PPTX, SVG, PNG, JPG, WebP or image ZIP. Up to 30 MB.

This wraps your export in a local .canva-import.json file. It does not extract Canva's original layers.

3

Continue in the editor

Choose the transfer file in the editor's import dialog. You can also import the original download directly.

Editor address

HTTPS, or HTTP on your own localhost. The default opens the local development server.

Local files only. No Canva account connection is needed. Import results depend on the exported file; some content remains an image.
